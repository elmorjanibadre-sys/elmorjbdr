◎ Lancer Souk Radar sur Windows

Guide pas à pas avec l'invite de commandes (cmd).

1 Installer les outils (une seule fois)

  • Node.js version 22.13 ou plus récente : version « LTS » sur nodejs.org
  • Git : git-scm.com

Ferme cmd et rouvre-le, puis vérifie l'installation :

node -v git --version

node -v doit afficher v22.13 ou plus.

2 Télécharger le projet

cd %USERPROFILE%\Desktop git clone -b claude/blissful-fermi-hqx85f https://github.com/elmorjanibadre-sys/elmorjbdr.git cd elmorjbdr\radar

Si GitHub demande de te connecter, utilise ton compte GitHub (le dépôt est peut-être privé).

3 Lancer Souk Radar

npm start

Ce message doit apparaître :

Souk Radar : http://localhost:4000 (scan des boutiques toutes les 60 min)

4 Ouvrir l'outil

Dans ton navigateur (Chrome, Edge…), va sur http://localhost:4000

  • Laisse la fenêtre cmd ouverte tant que tu utilises l'outil.
  • Pour l'arrêter : Ctrl + C dans cmd.

5 Les fois suivantes

cd %USERPROFILE%\Desktop\elmorjbdr\radar npm start

Pour récupérer la dernière version du projet, dans le dossier elmorjbdr :

git pull

? En cas de problème

« node n'est pas reconnu… » Node.js n'est pas installé, ou cmd n'a pas été rouvert après l'installation.
Le port 4000 est déjà utilisé Lance sur un autre port, puis ouvre http://localhost:5000
set PORT=5000 npm start
